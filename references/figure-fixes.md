# 图的构图手册

图的问题分两层：**构图**（占 70%）决定第一眼，**细节**（legend、刻度、字号）决定第二眼。不要反过来。

## 总原则：图也是一块矩形

版面是矩形拼矩形。图要能填满它占据的那一格——栏宽（单栏图）或版心宽（跨栏图），并且自身是**长条矩形**（宽 > 高）。正方形或竖图会让上下出现大片空白，是"不均匀空白"的主要来源之一。

| 图的类型 | 推荐宽高比 | 说明 |
|---|---|---|
| 结果曲线 / 柱状 | ≥ 3:1，跨栏图可到 4:1 | 越扁越贴合两栏文字块 |
| 多子图并排 | 每个子图 3:2 ~ 4:3，整体横向拼 | 子图高度必须一致 |
| 流程图 | ≥ 4:3，长大于宽，"越长越好" | 横向铺满栏宽 |
| 消融/热力图 | 接近 1:1 | 只有这类可以方 |

## 结果图

### 构图

1. **一张图一件事**。不要在一张图里塞三种量纲的曲线——reviewer 读不出重点，也排不出整齐的图例。
2. **横向铺满**。`width=\linewidth` 是起点，不是终点；如果撑满后元素显得稀疏，说明该加内容（更多 baseline、更多数据点），而不是保持窄条。
3. **多子图等高**。并排的子图必须共用 x/y 刻度（`sharex`/`sharey`），否则两图高度不同、与页上沿的边距不一致。
4. **图注只写看图需要的信息**：什么数据、什么设置、越少越好。不要把结论写进 caption。

### 细节

- **legend 不压数据**：移出绘图区，或放在图内空白象限（先确认那个象限真的空）。
- **刻度线朝内**，四边都有 tick（学术期刊惯例）；
- 曲线颜色在灰度打印下仍可区分（用线型 + 颜色双重编码）；
- 字号不小于图注字号，缩放后仍可读（作画时按最终宽度定字号，不要导出后再缩）。

```python
import matplotlib.pyplot as plt
fig, axes = plt.subplots(1, 3, figsize=(7.0, 2.1), sharey=True)  # 横向长条
for ax in axes:
    ax.tick_params(direction="in", top=True, right=True)
axes[-1].legend(bbox_to_anchor=(1.02, 1), loc="upper left", frameon=False)
fig.tight_layout(pad=0.3)
fig.savefig("figs/result.pdf", bbox_inches="tight")   # 矢量
```

导出用 PDF/SVG，不要 PNG（缩放会糊）。

## 流程图 / 框架图

### 构图（决定成败）

1. **横向铺满栏宽**，整体宽高比 ≥ 4:3，长大于宽。
2. **按模块分区**：用虚线框或底色卡片分出 Encoder / Router / Decoder 这类模块，**模块名写在卡片角上**，让读者能把图的每一块对应到 Methods 的某一节。
3. **空白成比例**：卡片之间的间距 > 卡片内组件之间的间距，两者都 > 组件与卡片边框的间距。任何一处"这里挤、那里空"都会被看出来。
4. **数据流方向单一**：从左到右（或从上到下），不要来回折返。
5. **颜色要克制**：底色卡片 + 一个强调色（标出本文的模块）足够；彩虹配色会让图显得业余。

### 细节

- 箭头粗细一致，转折处用直角或统一弧度；
- 张量维度用小字号标在箭头旁，不要写在框里；
- 同一层级的组件大小一致（尤其是圆角框）；
- 图中文字字号 ≈ 图注字号，缩放后不小于 6pt；
- 位图导出时 300 dpi 起步，矢量优先。

## 导出前自查（30 秒）

2. 图例有没有碰到任何一条线/点？
3. 并排子图的高度和刻度是否一致？
4. 撑满了吗？两侧还有没有白条？
5. 变形了吗（宽高比是否被单独拉伸）？
6. 灰度打印还能读吗？
