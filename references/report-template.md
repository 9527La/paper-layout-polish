# 报告模板（Phase 1 交付物）

报告的唯一目的：**让用户能在一分钟内决定"改哪些"**。所以每条都要有位置、实测数字、代价，以及两种修法。

---

## 结构

```markdown
# 版面审计：<paper>.pdf

- 页数 N｜版面 612×792pt｜2 栏｜栏宽 229.0pt｜版心宽 468.0pt
- 正文字号 10.0pt｜行距 12.0pt
- 段落末行：共检出 N 个段落结尾｜<50% 的 x 条｜50–70% 的 y 条｜中位占比 z%
- 候选问题 P0 a｜P1 b｜P2 c｜P3 d

## 我需要你决定的（先看这段）
一句话说清"最伤观感的是哪 2–3 处"，并说明是否只修 P0 会留下可见的不齐。

## P0 · 一眼可见
| ID | 位置 | 实测 | 破坏了什么 | 修法 A（改文本） | 修法 B（改版式） |
|---|---|---|---|---|---|
| OVE-07 | p1 栏 2 | 公式右溢 71.9pt，越过页边距 | 正文右侧边界出现一根突刺 | 拆成两行（在 = 处断） | 定义更短的符号替代 |
| WID-01 | p1 栏 1 第 3 段 | 末行占 17% 栏宽 | 段落右下角缺一块 | 删 4 个词压回上一行 | \looseness=-1 |

## P1 / P2 / P3 （同上，可用列表）

## 裁剪图
![OVE-07](crops/ove-07-p1.png)
（每条图/表问题一张，用户可能只看图）

## 人眼复核补充
- p2 的 Fig. 3 图例压住了红色曲线；
- p1 两个子图 y 轴刻度条数不同（5 vs 3）；
- ...

## 需人工确认的几何判定
说明哪些条目你判断为"可以不动"，以及原因（语义单元、跨栏表、单栏摘要等）。

---
改哪些？可选：**全部** / **只修 P0** / **按 ID 挑** / **先不改**。
```

---

## 条目写作要求

- **实测用数字**：`末行占比 17.4%`、`右溢 71.9pt`、`表宽 110/229pt（48%）`。不要写"太窄""有点空"。
- **"破坏了什么"要具体**：是右侧边界出现突刺、还是段落右下角缺一块、还是两张表字号不一致。
- **两种修法要区分代价**：改文本动语义（需用户确认措辞），改版式动全局（会产生新的空白）。把代价写出来，用户才能选。
- **寡行不要逐条列 30 条**：给汇总统计 + 最差的 8–10 条，说明"其余同类，修完这批会重新扫描"。
- **裁剪图必须挂**：图/表问题一张裁剪图胜过三行描述。

## Phase 2 的确认语

```markdown
按你的选择，本轮执行清单：
- ✅ OVE-07（拆公式）✅ WID-01 WID-04（删词压回）
- ⏭️ TAB-14（跳过：表只有三列，撑满会显空）
- ⏭️ SOU-15/16（保留 subsubsection，你要求保留原始章节结构）

共 3 条，开始执行。
```

清单外的事项一律不动；执行中如果发现某条改不动（例如压回需要删信息），**停下来问**，不要自行扩大改动。
